# Karoo Organics Q4 Performance Dashboard

## Overview

This project automates quarterly agricultural sales reporting for Karoo Organics.

## Features

* Database schema design
* Sales target tracking
* Regional revenue reporting
* Supplier ranking
* CSV report generation

## Technologies Used

* Python
* SQLite
* SQL
* VS Code

## Files Included

* schema.sql
* data.sql
* analytics.sql
* generate_q4_report.py
* q4_performance.csv

## How To Run

Run the following command:

python generate_q4_report.py
